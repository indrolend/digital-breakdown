# Runtime assets

This public repository intentionally excludes music, sound effects, TV clips,
and models whose redistribution rights have not yet been confirmed.

The source code and automated tests can be studied and modified under
AGPL-3.0. A complete playable build additionally requires appropriately
licensed replacements in:

- `native-desktop/audio/`
- `native-models/`
- `native-tv-gifs/`
- `native-android/app/src/main/res/raw/`

Do not submit copyrighted media unless its license explicitly permits
redistribution and the attribution is added to `docs/ASSET_CREDITS.md`.
