## Embedded and generated code

- `reference/browser-pass7/` is project reference code, but its embedded media
  has separate licenses recorded in `inventory.csv`.
- `multiplayer-server/worker-configuration.d.ts` is generated by Wrangler and
  should be regenerated from the pinned tool rather than manually maintained.
- `android/` contains Capacitor-generated project files. Generated status does
  not remove upstream license obligations.
- No configured Git submodule was found in `.gitmodules`.

## Release notice requirements

Before an official release:

1. generate a complete dependency graph for each platform;
2. archive exact resolved versions, not only semver ranges;
3. ship AGPL-3.0, Apache-2.0, BSD-3-Clause, MIT, zlib, and OFL notices that apply;
4. include source-offer and network-source instructions for the official Worker;
5. record compiler, SDK, NDK, CMake, Gradle, and package-manager versions;
6. rerun license scanning after every lockfile or FetchContent change.

This is an engineering audit, not legal advice.
