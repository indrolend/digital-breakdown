# Asset Replacement Plan

This plan distinguishes completed legal remediation from optional final-art
work. The current generated placeholders are legally safe and functional.

## Completed critical remediation — 2026-07-29

- Removed the uncleared embedded phone GLB and both derived native meshes.
- Removed proprietary/unverified MP3s from desktop, Android, and browser source.
- Replaced every required cue and music state with deterministic project audio.
- Replaced every archive-derived TV clip with an original abstract signal.
- Replaced the phone with project-created native and procedural browser forms.
- Removed the archive download tool and added a release gate.

The older sections below remain as rationale. Their critical legal-remediation
actions are complete; future replacement is creative polish unless a new
provenance issue is discovered.

## Priority 0: public-release blockers

### Fictional smartphone

Current rows: embedded phone GLB and both baked `phone.dbmesh` copies.
Status: `REPLACE` · Risk: `Critical`

Commission or create a fictional smartphone with original industrial design,
no Apple marks, and no confusing Apple trade dress. Preserve the current
gameplay collision and screen-coordinate contracts; visual replacement must
not redefine simulation dimensions.

Acceptance evidence:

- editable source file and export recipe;
- project copyright assignment or contributor license record;
- no third-party logo or proprietary UI;
- new runtime mesh on all platforms;
- old GLB removed from embedded browser source;
- model parity and phone-display tests still pass.

### Original phone and interface sound library

Current rows: capture, power, message, payment, call, ringtone, acknowledgment,
and phone-attack cues.
Status: `REPLACE` · Risk: `Critical`

Create a coherent original library with a minimal, tactile, digital character.
Keep an editable synthesis/session source and render master WAV files before
deriving delivery formats. Avoid imitating the melody, rhythm, or timbre of
recognizable operating-system sounds.

Acceptance evidence:

- project-owned recordings or synthesis sessions;
- cue sheet mapping every old runtime event to a new file;
- source WAV, delivery render, SHA-256, author, and date;
- no Apple-extracted samples;
- desktop and Android playback smoke tests.

### Music

Current rows: `menu_music.mp3`, `game_music.mp3`, and `game_over.mp3`.
Status: `REMOVE` · Risk: `Medium` for the confirmed game/menu compositions;
`REMOVE` · Risk: `Critical` for the still-unconfirmed game-over track.

Joel Gutierrez confirmed authorship of the former game and menu music on
2026-07-29. Before restoring either track, archive its project/session source,
document any samples or third-party instruments that affect redistribution, and
record the intended release license. The finished renders remain absent until
that review is complete. Continue treating `game_over.mp3` as unverified.

### Unknown combat and reward effects

Current rows: headshot effects and reward voice clips.
Status: `UNKNOWN` · Risk: `High`

Recover the recording/source sessions and performer consent, or make new
project-owned cues. Treat spoken interjections as performances requiring
permission, not merely anonymous sound effects.

## Priority 1: high-risk visual replacements

### TV clips

Current rows: `native-tv-gifs/tv*.dbgif`.
Status: `REPLACE` · Risk: `High`

Replace the archive-derived clips with project-created pixel animations. Store
the editable source, frame-generation method, and deterministic baker inputs.
Preserve the DBGF runtime format only if it remains technically useful.

### Launcher, splash, and identity graphics

Current rows: Capacitor Android splash and launcher PNG families.
Status: `TEMPORARY` · Risk: `Medium`

Create Data-specific identity artwork after the naming decision. Generate all
Android density variants from one project-owned master rather than editing
variants independently.

## Priority 2: verify or replace

### Door knock

Status: `UNKNOWN` · Risk: `Medium`

Request or locate an explicit license from Soundspace Sound Effects. If the
license cannot be archived, record a new knock or use a clearly licensed
library file. A YouTube description or download URL alone is not evidence of
redistribution rights.

### TV-room ambience

Status: `TEMPORARY` · Risk: `Medium`

Confirm the FL Studio project, author, and every sample/loop license. If the
track is wholly synthesized or uses cleared bundled content, preserve the
session and render record. Otherwise replace it.

### Sketchfab Free Standard candidates

The CRT TV is not a current baked native runtime model, but it remains a
candidate. Do not add it to public source. Prefer an original or CC BY/CC0 model
whose source redistribution is compatible with independent rebuilding.

## Identity standard

Legal permission is the minimum threshold, not the design goal. Retain an asset
only if maintainers would intentionally choose it for Data ten years from now.
Temporary assets should remain visibly temporary in the inventory until they
are removed from every official release surface.
